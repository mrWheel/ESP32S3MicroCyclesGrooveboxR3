Card Storage Screen

Accessing Card Storage

Card Storage is where you manage all your pattern groups on the SD card. To access it:

  1. From the main [Groovebox] screen, press encoder (long press) to open System Settings
  2. Find and select Card Storage
  3. The Card Storage menu opens

Card Storage Menu

Menu Item What It Does
Save Group * Write your current patterns to SD card. An asterisk (*) appears if you've made unsaved changes.
Load Group Load a previously saved pattern group from SD card into memory
New Group Create a new empty pattern group and give it a name
Rename Group Change the name of the current pattern group
Copy Group Duplicate the current group with a new name (great for backup or variations)
Delete Group Remove a pattern group from SD card (careful—this can't be undone)

Understanding the Asterisk (*)

You'll notice an asterisk (*) on some menu items, particularly "Save Group":

  • Asterisk appears when you've edited patterns but haven't saved them to SD card yet
  • No asterisk means all your current work is saved
  • If you power off with unsaved changes, you'll lose them
  • Always save before turning off the Groovebox if you want to keep your work

Workflow: Save Your Patterns

  1. Edit your patterns on the main Groovebox screen
  2. When satisfied, press encoder (long press) → System Settings → Save Group
  3. Your work is now on SD card and won't be lost
  4. The asterisk disappears from "Save Group" to show everything is saved

Workflow: Load a Previous Group

  1. Press encoder (long press) → System Settings → Card Storage → Load Group
  2. Select the group you want (you'll see a list of saved groups)
  3. Press encoder (short press) to load it
  4. The group's patterns fill your memory, replacing what was there

Note: Unsaved changes to the current group are lost if you load a different group without saving first.
