Tempo Screen

About Tempo

Tempo controls the speed of your patterns, measured in BPM (beats per minute). Higher BPM = faster music. Lower BPM = slower music.

The Groovebox lets you set tempos from 40 to 260 BPM, covering everything from slow, heavy music to fast, frenetic breakbeats.

Accessing the Tempo Popup

From the main [Groovebox] screen (not in track edit mode):

  1. Press the encoder button (MEDIUM PRESS), OR
  2. Press the KEY0 button (MEDIUM or SHORT PRESS)

A popup menu appears with three parameters you can adjust right now.

The Popup Menu

When you open the tempo popup, you'll see three editable values:

Parameter Range What It Does
BPM 40–260 Sets the speed of your patterns (beats per minute)
SW (Swing) 0–45% Adds groove by delaying odd-numbered beats
GAIN (Volume) 10–260% Controls the master output level

How to Use the Tempo Popup

The popup shows three parameters with one highlighted:

Tempo
   >BPM<    120
    SW       50%
    GAIN    045%
  1. Navigate between parameters: Rotate the encoder to scroll through BPM, SW (Swing), and GAIN. The highlighted parameter shows a `>` on each side.
  2. Edit a parameter value: When a parameter is highlighted, press the encoder (short press) to enter edit mode for that value
  3. Change the value: Now rotate the encoder to increase or decrease the value: 
    Tempo
    BPM     >120<
    SW       50%
    GAIN    045%
  4. Confirm the value: Press the encoder (short press) again to lock in the new value and return to parameter selection
  5. Close the popup: Press the KEY0 button (short press) to close the popup and return to the main screen

Tip: Changes take effect immediately—you can keep playing while adjusting tempo and gain.
