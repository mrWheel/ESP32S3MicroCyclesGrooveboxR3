System Settings

Opening System Settings

From the main [Groovebox] screen (not in track edit mode):

  1. Press the encoder button (LONG PRESS) — hold for about 1 second

The System Settings menu appears with the following options:

System Settings Menu

Menu Item What It Does
Save Group * Save your current pattern group to the SD card. An asterisk (*) appears if you've edited patterns but haven't saved yet.
Add Pattern Create a new empty pattern slot in the current group
Delete Pattern Remove the current pattern
Card Storage Open the Card Storage menu for managing pattern groups (save, load, copy, rename, delete)
Load Sample Set Switch to a different drum kit or sample set
Erase WiFi Credentials Forget the current WiFi network settings
Start WiFi Manager Open the WiFi setup portal to connect to a new network
Rotate Display Rotate the screen orientation (technical setting)
Encoder Order Reverse the encoder direction if it feels backwards (technical setting)
Restart Groovebox Reboot the device

The Dirty Marker (*)

When you see an asterisk (*) next to "Save Group", it means:

  • You've made changes to your patterns
  • These changes are in memory but not yet saved to SD card
  • If you power off without saving, you'll lose your work
  • Use "Save Group" to preserve your changes

Using System Settings

  1. Rotate the encoder to move up/down through the menu
  2. When an item is highlighted, press the encoder to select it
  3. Follow the on-screen prompts for the selected action
  4. Press encoder long press to exit back to the main Groovebox screen
