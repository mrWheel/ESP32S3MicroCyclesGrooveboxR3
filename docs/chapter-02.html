Controls

Your Control Interface

The Groovebox has two main controls:

  • An encoder (rotary knob with push button)
  • A KEY0 button (auxiliary button)

By combining rotations and different press types (short, medium, long), you can control every function on the device.

The Encoder Knob

Rotate (turn the knob)

  • On main screen: Move the track cursor up/down to select which drum to edit
  • In menus: Move up/down through menu items
  • Editing values: Change the selected value up or down

Short Press (quick tap)

  • On main screen: Enter track edit mode to change triggers, velocity, pitch, etc.
  • In menus: Confirm selection or open submenu
  • In popups: Confirm choice and close popup

Medium Press (hold ~0.3 seconds)

  • On main screen (not in edit mode): Open the Tempo Popup to adjust BPM, Swing, and Master Gain. Scroll through parameters with encoder rotation; press to edit.
  • In track edit mode: Open the Edit Popup with options for Velocity, Pitch, Decay, Probability, Mute, and Chain. Works the same way—rotate to scroll, press to edit values.

Long Press (hold ~1 second)

  • On main screen (not in edit mode): Open System Settings menu
  • In menus or System Settings: Go back to the previous screen

The KEY0 Button

Short Press (quick tap)

  • On main screen: Play/Stop playback of the current pattern

Medium Press (hold ~0.3 seconds)

  • On main screen (not in edit mode): Opens the same Tempo Popup as encoder medium press — adjust BPM, Swing, and Master Gain

Long Press (hold ~1 second)

  • On main screen (not in edit mode): May trigger alternate functions depending on context (reserved for future use)

Modes Explained

Mode What It Is How to Enter How to Exit
Browse Mode Main screen showing your pattern and all tracks Default when Groovebox starts Always the default
Edit Mode Editing a specific track's parameters Select a track and press encoder (short press) Press encoder short press again
Tempo Popup Quick access to BPM, Swing, and Gain Press encoder (medium press) or KEY0 (medium press) Press encoder (short press) to confirm
Edit Popup Edit Velocity, Pitch, Decay, Probability, Mute, Chain of current step In track edit mode, press encoder (medium press) Press encoder (short press) to confirm
System Settings Save/load groups, sample sets, WiFi, display settings Press encoder (long press) from browse mode Press encoder (long press) to go back

Quick Tips

  • Lost? Press encoder long press to go back to System Settings, then exit again to get to the main screen.
  • Double-check press timing: If a button doesn't do what you expect, you might be doing a short press when you need a medium or long press.
  • Play while editing: You can edit patterns while the sequencer is playing—changes take effect immediately in the next loop.
