Chain

What is Chain?

Chain allows you to link patterns together so they play one after another automatically. Instead of manually switching between patterns, you can set up a sequence that the Groovebox plays through.

Think of it like creating a song structure: Intro → Verse → Verse → Chorus → Verse → Chorus → Outro.

Chain Basics

Example: Linear chain

P01 → P02
P02 → P03
P03 → P04
P04 → P01 (loop back)

Result: The Groovebox plays P01, then P02, then P03, then P04, then repeats.

Example: Custom loop

P01 → P02
P02 → P03
P03 → P02 (loop back to P02)

Result: P01 plays once, then P02 and P03 alternate forever (endless groove).

Setting Up a Chain in the Edit Popup

When you're in the Edit Popup for a step and highlight the "CHAIN" parameter, you'll see three editable fields:

CHAIN >ON< L5 p02
Field What It Means
ON / OFF Enable or disable chaining. ON = chain active, OFF = single pattern
L5 Chain length (number of patterns in the chain). L5 = 5 patterns
p02 Next pattern number. Which pattern plays after this one finishes

How to Edit Chain Settings

  1. In the Edit Popup, highlight "CHAIN" and press the encoder (short press)
  2. A cursor appears on the first field (ON/OFF): `>ON<`
  3. To toggle ON/OFF: Rotate the encoder to switch between ON and OFF
  4. Move to next field: Press the encoder (short press) to move to the chain length field: `L>5<`
  5. To set chain length: Rotate the encoder to change how many patterns are in the chain (usually 1-8)
  6. Move to next field: Press the encoder (short press) to move to the target pattern: `>p02<`
  7. To set target pattern: Rotate the encoder to choose which pattern plays next (p01, p02, p03, etc.)
  8. Confirm: Press the encoder (short press) again to lock in all three chain settings

Using the Edit Popup

When you press medium press, a popup appears showing all editable parameters for the selected step:

Edit Step 5
    VELOCITY     100
    PITCH        +00
    DECAY        50%
    PROBABILITY  100%
    MUTE   OFF
   >CHAIN<       NO
  1. Navigate between parameters: Rotate the encoder to scroll through Velocity, Pitch, Decay, Probability, Mute, and Chain. The highlighted parameter is between `>..<`.
  2. Edit a parameter: When a parameter is highlighted, press the encoder (short press) to enter edit mode
  3. Change the value: For Chain, editing works differently than other parameters. When you press short press on CHAIN, a three-field display appears: 
    Edit Step 5
    VELOCITY     100
    PITCH        +00
    DECAY        50%
    PROBABILITY  100%
    MUTE   OFF
    CHAIN  >ON< L5 p02
  4. Edit Chain ON/OFF: The cursor starts on the first field (>ON<). Rotate to toggle between ON and OFF
  5. Move to chain length: Press encoder (short press) to move to L5. Rotate to set how many patterns are in the chain (usually 1-8)
  6. Move to target pattern: Press encoder (short press) to move to p02. Rotate to choose which pattern plays next (p01, p02, p03, etc.)
  7. Confirm all chain settings: Press the encoder (short press) to lock in all three values and return to parameter selection
  8. Continue editing: Repeat steps 1-7 to adjust other parameters
  9. Close the popup: Press KEY0 (short press) to close the popup. Your changes are saved.

Common Chain Patterns

4-pattern loop (building tension):

P01 → P02 (intro)
P02 → P03 (verse 1)
P03 → P04 (verse 2)
P04 → P02 (loop verses)

Bridge to chorus:

P01 → P02 (verse)
P02 → P03 (break/fill)
P03 → P04 (chorus)

Endless groove:

P01 → P01 (loops forever)

Pro Tips

  • Test your chain: Set up a chain and press Play to hear how patterns flow together
  • Smooth transitions: Make sure the last step of one pattern lines up rhythmically with the first step of the next
  • Use fills: Insert a "fill" pattern between verse and chorus for dynamic transitions
  • Loop count: The loop count (L5) tells you how many patterns are in the chain—this helps you remember the structure
