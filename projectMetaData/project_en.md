# The Groovebox Project

**The Groovebox Project** is a standalone, sample-based drum machine on an ESP32. It allows you to create rhythmic patterns, chain them into complete songs, and play them back without the need for a computer.

Despite its compact hardware, the Groovebox features a multi-track step sequencer, high-quality sample playback, pattern storage on a microSD card, and a responsive user interface. It demonstrates how a modern embedded system can deliver surprisingly capable music production features on inexpensive hardware.

The project is fully open source and is intended for makers, musicians, and developers who enjoy building, experimenting, and learning about embedded audio systems.
