# The Groovebox Project

The Groovebox Project is een zelfstandige, sample-gebaseerde drummachine op basis van een ESP32. Hiermee kun je ritmische patronen maken, deze aan elkaar koppelen tot complete nummers en ze afspelen zonder dat daar een computer voor nodig is.

Ondanks de compacte hardware beschikt de Groovebox over een meerkanaals step-sequencer, hoogwaardige sample-weergave, opslag van patterns op een microSD-kaart en een intuïtieve gebruikersinterface. Het project laat zien hoe een modern embedded systeem verrassend uitgebreide mogelijkheden voor muziekproductie kan bieden met betaalbare hardware.

Het project is volledig open source en is bedoeld voor makers, muzikanten en ontwikkelaars die graag bouwen, experimenteren en meer willen leren over embedded audiosystemen.
